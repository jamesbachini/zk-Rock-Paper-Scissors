## Contract requirements
Implement contract storage and functions:
- init(game_hub: Address, verifier: Address, commit_window: u32, reveal_window: u32)
- create_session(session_id: u32, player1: Address, player2: Address)
- commit_move(session_id: u32, player: Address, commitment: BytesN<32>)
- reveal_move_mock(session_id: u32, player: Address, move_u8: u32)  // TEMP for now
- finalize(session_id: u32)

Events:
- SessionCreated { session_id, player1, player2 }
- MoveCommitted { session_id, player }
- MoveRevealed { session_id, player, move }
- Finalized { session_id, winner }

Rules:
- move encoding 0/1/2
- winner calc for all combos
- deadlines in ledger sequence:
  - commit_deadline = current + commit_window
  - reveal_deadline = commit_deadline + reveal_window
- forfeit logic per spec

GameHub integration:
- On create_session call GameHub.start_game(env, this_contract_address, session_id, player1, player2, 0, 0)
- On finalize call GameHub.end_game(env, session_id, player1_won_bool)
- Tie must still finalize: winner=0, player1_won=false

Verifier:
- store verifier address but do not call yet; reveal uses mock path
