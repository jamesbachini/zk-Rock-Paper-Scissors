# 04 — Frontend MVP: create/join, commit, reveal(prove), finalize

## Goal
Build the browser frontend that:
- Connects wallet (Stellar Game Studio interface conventions)
- Lets users create/join a session_id
- Allows commit:
  - choose move
  - generate salt via crypto.getRandomValues
  - compute commitment (exactly matches circuit)
  - submit commit_move tx
  - store salt locally scoped by (session_id, player_address)
- Allows reveal:
  - load salt
  - generate Ultrahonk proof in-browser via bb.js
  - submit reveal_move(proof, public_inputs) tx
- Allows finalize and shows winner.

## Constraints
- No backend
- Proof generation MUST be browser-side with bb.js
- Use Soroban RPC calls from the browser
- Handle errors clearly (missing salt, proof failure, deadlines)

## Tasks
1) Scaffold frontend (Vite/React recommended).
2) Wallet connect + Soroban RPC client wiring.
3) Session screens:
   - Home: create session (session_id random u32), join session
   - Commit: select move, commit tx, store salt
   - Reveal: generate proof with bb.js, submit reveal tx
   - Finalize: call finalize, display outcome
4) Contract reads:
   - Poll session state from contract storage (or call view functions you add)
   - Display deadlines, commit/reveal status
5) Add a small “dev mode” for local testing:
   - Two browser profiles can play
   - Optional: friendbot funding helper for testnet accounts

## Completion criteria
- Two real testnet accounts can complete a full game using only the frontend:
  - create_session -> both commit -> both reveal with proofs -> finalize -> show winner
- Proof generation happens in the browser (no node-only path)
- The UI persists salt and warns users about losing it
